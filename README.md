# Shuhan Guo — Personal Homepage

A lightweight academic homepage inspired by
[luost26/academic-homepage](https://github.com/luost26/academic-homepage).

## Preview

Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages

1. Create a public GitHub repository named `<your-username>.github.io`.
2. Upload every file in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. The website will appear at `https://<your-username>.github.io/`.

## Contact links

The email and GitHub profile are defined in the `social-links` block in `index.html`.

## Update content

- Portrait: `assets/images/portrait.png`
- Main text and sections: `index.html`
- Colors and layout: `assets/style.css`
- Project files: `assets/files/`
