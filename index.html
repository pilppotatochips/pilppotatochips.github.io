Lighbrary — Adaptive Lighting System for Libraries

Introduction to Engineering · Group Project · 2025

01

Collaborated in a four-person team to design and prototype an Arduino-based adaptive lighting and shading system for libraries. The prototype used occupancy, UV, and light sensors to control LED brightness and motorized blinds, with touchscreen support for manual adjustment.

My contribution: materials procurement, presentation and report preparation, simulation-environment setup, and system assembly.

Used-Car Price Analysis

Data Science for Future Engineers · Group Project · 2026

02

Contributed to a team analysis of a 301-record used-car dataset in Python. The project covered data cleaning, feature engineering, exploratory visualization, hypothesis testing, and multiple linear regression.

The revised model corrected categorical-variable encoding and used heteroscedasticity-robust standard errors, achieving an adjusted R² of approximately 0.890.
